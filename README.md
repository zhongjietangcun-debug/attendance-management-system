# 出席管理システム（Attendance Management System）

## 1. 概要

HTML、CSS、JavaScriptで開発した出席管理Webアプリケーションです。

生徒の登録や出欠管理に加え、検索機能、月別集計、グラフ表示などを実装しています。

AIを開発支援に活用しながら、設計、実装、動作確認、バグ修正を行いました。

## 2. 主な機能

- 生徒の登録・削除
- 生徒名による検索
- 重複登録の防止
- 日付ごとの出席・欠席・遅刻の管理
- 出席人数・出席率の自動集計
- 月別出席率と生徒別集計
- 出席率のグラフ表示
- CSV形式でのデータ出力
- JSON形式でのバックアップ・復元
- LocalStorageによるデータ保存
- ダッシュボード形式の管理画面

## 3. 使用技術

| 技術 | 用途 |
|---|---|
| HTML | 画面構造 |
| CSS | デザイン |
| JavaScript | 出席管理・集計・画面操作 |
| LocalStorage | ブラウザ内のデータ保存 |

## 4. 起動方法

1. プロジェクトのファイルを同じフォルダに保存します。
2. VS Codeでフォルダを開きます。
3. ローカルサーバーを起動します。

Pythonがインストールされている場合：

```powershell
py -m http.server 8000
```

4. ブラウザで `http://localhost:8000` を開きます。

## 5. 集計方法

**日別出席率**

出席人数 ÷ 登録人数 × 100

**月別出席率**

出席の延べ人数 ÷ 記録済みの延べ人数 × 100

月別集計では未記録を分母から除外し、遅刻は出席に含めません。

## 7. 注意事項・制限

- 学習・デモ用に開発した試作品です。
- 実際の生徒の個人情報は登録しないでください。
- データはブラウザのLocalStorageに保存されます。
- 複数端末間のデータ共有には対応していません。
- ログイン認証、サーバー管理、アクセス権限管理は実装していません。
- 本番運用にはセキュリティ対策などの追加開発が必要です。
