# 出席管理システム | Attendance Management System

HTML・CSS・JavaScriptを使用して開発した、出席記録と集計を行うWebアプリケーションです。

生徒の登録・検索・出欠管理に加え、月別集計、グラフ表示、データのバックアップ機能を備えています。

## 開発で工夫した点

### 1. 見やすい管理画面

出席状況や集計結果をダッシュボード形式で表示し、必要な情報を確認しやすくしました。

### 2. 月別集計とグラフ

日付ごとの出席記録から月別の出席率を求め、グラフで可視化しました。

### 3. データの保存と復元

LocalStorageを使用してブラウザ内にデータを保存し、JSONファイルからバックアップ・復元できるようにしました。

### 4. 既存データとの互換性

初期バージョンの保存データを、拡張版でも利用できるようにしました。

### 5. AIを活用した開発

ChatGPTをコード生成、機能拡張、エラー調査、品質テストの支援に利用しました。実際のブラウザで動作を確認し、発見した不具合を修正しました。

## 出席率の計算仕様

**日別出席率**

出席人数 ÷ 登録人数 × 100

**月別出席率**

出席の延べ人数 ÷ 記録済みの延べ人数 × 100

遅刻は出席に含めず、月別出席率では未記録を分母から除外します。

## ローカル環境での起動方法

1. プロジェクトのファイルをPCに保存します。
2. `index.html`、`style.css`、`script.js` が同じフォルダにあることを確認します。
3. Pythonがインストールされている場合は、そのフォルダで以下を実行します。

```powershell
py -m http.server 8000
```

4. ブラウザで `http://localhost:8000` を開きます。

## 制限事項

- 学習・デモ用の試作品です。
- データは利用者のブラウザ内に保存されます。
- 複数端末間のデータ共有には対応していません。
- ログイン認証や権限管理には対応していません。
- 実際の学校・塾などで使用するには、個人情報保護やセキュリティ面の追加開発が必要です。
